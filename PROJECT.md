# Project Metadata / 프로젝트 메타데이터

## Overview / 개요

Agent Archives is a desktop app for browsing Claude Code and OpenCode session history. This repository is a public fork of `johnfkoo951/agent-archives`.

Agent Archives는 Claude Code와 OpenCode 세션 히스토리를 탐색하는 데스크톱 앱입니다. 이 레포는 `johnfkoo951/agent-archives`의 공개 fork입니다.

## Purpose / 목적

- Browse local agent session history in a desktop interface.
- Search, tag, and resume development sessions.
- Help people and AI tools understand this repository as a forked developer-tool project with upstream attribution.

- 로컬 에이전트 세션 히스토리를 데스크톱 UI에서 탐색합니다.
- 개발 세션을 검색하고 태그를 붙이며 이어서 작업할 수 있게 합니다.
- 사람과 AI 도구가 이 레포를 upstream 표시가 필요한 fork 개발 도구로 이해하게 합니다.
